# Superliga predikce

Webová aplikace s predikcemi zápasů, kartami hráčů a statistikami Livesport Superligy florbalu.

Otevři **https://michaelkocandrle.github.io/superliga/** a přidej si ji na plochu telefonu
(iPhone: Safari → Sdílet → Přidat na plochu; Android: Chrome → ⋮ → Přidat na plochu / Instalovat).

Data se čtou přímo ze Supabase veřejným klíčem jen pro čtení. Soubory v tomto repozitáři
generuje `web/build_web.py` z dashboardu – needituj je ručně.
